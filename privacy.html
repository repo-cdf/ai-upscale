Privacy

The AI Upscale app

The app runs entirely on your own computer. It never uploads your videos, never collects personal data and has no account system or analytics. After the one-time install (which downloads the AI models from their authors' official pages), it works fully offline.

This website

This is a static website hosted on GitHub Pages. We don't use cookies or analytics ourselves. GitHub may keep standard server logs (see GitHub's privacy statement).
